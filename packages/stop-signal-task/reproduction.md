# Reproduction of the literature values

How much of what the stop-signal-task literature varied can this package express, and does each setting show up in the data? The source is the generated spec (specs/countermanding/spec.yaml (jspsych-timelines-paper, vocabulary 2026-11-13-std-final)). The fixture is `reproduction/spec-observed.json`, generated by `@jspsych-timelines/testing` (`scripts/fixture-from-spec.mjs`); the retyping table is `reproduction/adapter.ts`; the checks are the shared checks of `@jspsych-timelines/testing` plus `reproduction/checks.ts`, run by `src/reproduction.spec.ts`. The tallies below come from `reproduction/results.json` and are asserted against `reproduction/expected-tallies.json` on every test run. `UPDATE_REPRODUCTION=1 npx jest` regenerates both and this file.

This file is generated. Commentary that belongs to the package goes in `reproduction/notes.md`, which is appended at the end.
