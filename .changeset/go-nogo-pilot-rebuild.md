Rebuilt from the literature-derived spec. Breaking: all options are snake_case under vocabulary names (`num_blocks` is now `n_blocks`, `num_trials` is `n_test_trials` (the total, split over blocks), `trial_timeout` is `response_window_ms`, `stimulus_duration` is `stimulus_duration_ms`, `isi_duration` is `iti_ms`, `probability` is `condition_proportions: { go, nogo }`, `show_practice` and `num_practice_trials` are `practice_trials`, `block_break_duration` is gone), defaults follow the Experiment Factory go_nogo task (10 practice trials at 50% go with feedback, 350 test trials at 90% go, a 750 ms stimulus in a 1000 to 1500 ms response window, no ITI), the scorable row is now `part: "response"` with `condition`, `responded`, `correct`, `timeout` and `response_window`, scores are snake_case and add d', criterion, commission and omission rates and per-block rates, and the old demonstration trials are replaced by an interactive walkthrough built from the task's own stimuli (`instruction_demonstration`, default `"interactive"`: a go step then a no-go step that waits 2.5 s; a hint and a repeat after a wrong response, at most 3 attempts). New: ordering rules (`sequence_constraints`: `max_run`, `min_gap`, `max_gap`, `run_length`, `start_with`, `no_immediate_repeat`, `balanced_transitions`, `cycle_length`) through `@jspsych/sequencer`, jittered or computed response windows (`utils.deadlines.meanPlusSd`, `percentile`), go-only baseline blocks, stimulus sets of shapes, colours, text, images (URLs) and SVG markup (an item's `id`, which replaces the former `label`, is recorded as `stimulus`; a string is a text item; an item must give exactly one of `shape`, `text`, `image`, `svg`, and duplicate ids throw), keyboard, mouse and touch responses, a `practice` override, feedback, block feedback, response acknowledgement and a rule reminder. The default trial order is now an exact shuffled list (`trial_order: "shuffled_list"`).
