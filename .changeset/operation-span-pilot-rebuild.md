Rebuilt from the literature-derived complex-span spec (the package keeps its name; reading, symmetry and rotation span are not implemented). Breaking: all options are snake_case under vocabulary names (`setSizes` is now `set_sizes`, `trialsPerSetSize` is `trials_per_condition`, `letterDuration` is `stimulus_duration_ms`, `mathTimeout` is `response_window_ms`, `isi` is `inter_item_interval_ms`, `recallFeedbackDuration` is `feedback_duration_ms`, `showPractice`/`showInstructions` are `practice_structure: "none"` and `instruction_format: "experimenter"`), the processing deadline defaults to the anchor's calibrated rule (mean + 2.5 SD of the practice solution times, `utils.deadlines.meanPlusSd(2.5)`) instead of no limit, practice has the anchor's three parts (letters only, processing only, combined), the scorable row is now the recall (`part: "response"`, one per trial, with `recalled_items`, `recall_correct_positions`, `set_size`) and the old per-trial `math_problems` arrays are separate `part: "processing"` rows, and the scoring result is snake_case (`partial_credit_load`, `partial_credit_unit`, `absolute_score`, `processing_accuracy`, ...). The old try-it instruction trials are replaced by an interactive walkthrough built from the task's own problems and recall input. New: block orders including `random_within_block`, per-block `set_sizes` lists, two display formats, memory-item-first order, 0-2 problems per memory item, memory items as a stimulus set (`stimulus_set` takes a set `{ name?, noun?, items }` or an array of text items; the bundled `utils.stimuli.letters`, the default, and `utils.stimuli.digits`; rows record `stimulus_set`, `memory_item_id`, `presented_item_ids`, `recalled_item_ids`; the instructions use the set's noun), click-matrix, typed and key-press recall with serial or free order and blank/skip/? omissions, a practice criterion, mouse, touch and keyboard processing responses, `practice` overrides, deadline helpers (`meanPlusSd`, `percentile`). Breaking within the rebuild: the items to remember are "memory items", not "memoranda" (`memorandum_order_in_pair` is `order_in_pair` with `"memory_item_first"`, `processing_items_per_memorandum` is `processing_items_per_memory_item`, the data part `"memorandum"` is `"memory_item"` with `memory_item` and `memory_item_id`, the timeline unit `createMemorandum` is `createMemoryItem`); `stimulus_set` takes the set itself (`stimulus_set.memorandum` and `stimulus_set.memorandum_source` are gone; memory items are always separate screens); `stimulus_set` no longer takes `"letters"`, `"digits"` or `{ words }` (pass `utils.stimuli.letters`, `utils.stimuli.digits` or a set); `utils.stimuli.memorandumPool` is replaced by `utils.items.buildPool`; the texts `emphasis_both`, `practice_storage_intro` and `instruction_test_intro` are functions of `{ noun, nouns }`, and the texts that named letters take `noun` and `nouns`.
