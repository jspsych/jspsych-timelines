Rebuilt from the literature-derived spec (anchor: STOP-IT). Breaking: all options are snake_case under vocabulary names (`numTestTrials` is now `n_test_trials`, `fixationDuration` is `fixation_duration_ms`, `responseDuration` is `response_window_ms`, `interTrialInterval` is `iti_ms`, `stopProbability` is `condition_proportions`, `initialSSD`/`ssdStep`/`minSSD`/`maxSSD` are fields of the `adaptive` bundle), the `@jspsych-contrib/plugin-stop-signal` image plugin is gone (the stop signal is now inside one keyboard or button trial, on the same anchored stage), the scorable row is `part: "response"` with the trial type in `condition` (`go` | `stop`), the stop-signal delay is `ssd` (requested) and `ssd_actual` (measured), and the scoring result is snake_case with the integration SSRT (omissions replaced), the mean method and the consensus checks. Needs jsPsych 8.4.0 (`jsPsych.adaptive`): the stop-signal delay is a staircase with `procedure`, `start_level`, `step_size` (`{ up, down }`), `target_accuracy`, `bounds`, `discontinue_rule`, `tracks` (`single` | `per_condition`) and `reset` (`never` | `block` | `phase`), and its state is recorded in the data. New: fixed delays (`difficulty_levels`), per-block stop proportions as a list of maps, ordering rules (`sequence_constraints`, default 8-trial cycles), practice criterion with repeat, interactive walkthrough, auditory and visual signals, keyboard/mouse/touch.
