New package: self-ordered pointing (Petrides & Milner, 1982). N pages of N items, one pick per page, a repeat is an error. Mouse and touch on an anchored item grid, seeded own abstract designs plus word and nonword pools (or your own text or images), full or partial reshuffle between pages, fixed grid or free positions, nested or distinct item pools across set sizes, set sizes and series per size, five block orders, an optional position-repeat rule (instructed, enforced, or detected with a reminder), an interactive walkthrough with a hint after a repeat, practice with page feedback, a simulated participant whose repeat errors rise with set size, and scoring of total errors, errors by set size and choice order, accuracy, span before the first error, the largest clean set size and perseverations.
