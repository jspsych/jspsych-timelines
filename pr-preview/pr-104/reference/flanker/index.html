Flanker

Package: @jspsych-timelines/flanker (source). Version documented here: 0.0.1.

Overview​

The Eriksen Flanker Task measures inhibitory control and selective attention. On each trial the participant sees a row of five arrows and reports the direction of the center (target) arrow while ignoring the other four. The flankers point the same way as the target (congruent), the opposite way (incongruent), or are replaced by dashes (neutral). The extra time and errors on incongruent trials, relative to congruent trials, are the flanker effect.

This implementation is based on the PEBL Test Battery version of the task, with large touch-friendly response buttons.

Task Description​

Trial structure: fixation, then the arrow row with Left and Right buttons until a response or the response duration passes, then optional feedback, then an inter-trial interval. A practice block (with optional interactive instructions) comes first, then one or more test blocks. Congruent and incongruent trials cover both target directions; neutral trials are added when includeNeutral is true.

Try it​

For a short run, pick "Quick demo" in the Preset menu (the walkthrough, 4 practice and 12 test trials) and press Run. The other presets are study configurations from the literature. The task runs from the bundle built from this repository. The options are kept in the URL hash, so you can share a configuration.

Data Output​

Every trial carries task: "flanker" and task_version. The trial that records the response has these fields.

FieldTypeDescription
taskstring"flanker"
task_versionstringPackage version
phasestring"practice" or "test"
blocknumberBlock number (1-indexed)
trialnumberTrial within block (1-indexed)
target_directionstring"left" or "right"
congruencestring"congruent", "incongruent" or "neutral"
correct_responsenumberExpected button index (0 = left, 1 = right)
responsenumber or nullButton pressed (null on timeout)
correctbooleanWhether the response was correct
rtnumber or nullResponse time in ms (null on timeout)

part values the package writes today: instruction, instruction_feedback, fixation, stimulus, feedback, iti, transition. The final screen uses phase: "completion".

Translation​

Pass a text object to replace interface strings; partial objects are merged with the defaults. The string keys are listed in the text row of the parameters table. Three keys are functions (instruction_response, block_complete, result_summary) and can only be set from code.

createTimeline(jsPsych, {
  text: { left_button: "Izquierda", right_button: "Derecha", continue_button: "Continuar" },
});
