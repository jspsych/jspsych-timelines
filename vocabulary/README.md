# Options vocabulary

These are the shared option names, types and absent values that every timeline package uses (PACKAGE-STANDARD §2a).

- **`vocabulary.yaml`** lists 148 parameters, each with a name, layer, type, unit, definition, allowed values and absent value. There is one bundle, `adaptive`.
- **`RULES.md`** explains what counts as one parameter, how parameters are named, and how phase, roles and bundles are handled.

The vocabulary comes from a structured survey of how researchers vary 79 RDoC tasks in recent online studies and openly licensed reference implementations. It was standardized across tasks by three independent passes, a human decision on each contested rule, and a final reconciliation. Version: `2026-11-13-std-final`.

Edit these files only through that process. A change to an option name here is a breaking change for every package that uses it.
